My Claude Workflow

1

Describe the Problem

Start by explaining what you're trying to accomplish. Ask for potential solutions with explanations of trade-offs and approaches.

2

Generate Code & Examples

Ask for code implementation or generation of example outputs to validate the approach before committing.

3

Add Explanatory Comments

Request inline comments or text explanations to clarify the logic of generated code — helpful for future you and teammates.

4

Final Review After Editing

After making manual edits, paste the code back for a final review to catch typos, logical errors, or inconsistencies.

⚡ What Works Well

  • Generating tedious code — e.g., pattern detection follow-up in DEGenes
  • Logical back-and-forth for stats questions — e.g., linear models in DESeq2
  • Code review and correction for typos/errors

⚠️ What Needs Caution

  • Never upload private or sensitive data
  • Always follow up on sources for statistical claims
  • Review AI-generated code to verify it actually does what it claims

Quick Demo

Example: A typical 4-step conversation for a DESeq2 analysis question

# Step 1: Describe the problem

"""
I'm running DESeq2 on RNA-seq data and want to include
batch as a covariate in my linear model. I have 3 batches
and 2 treatment conditions. What's the best way to set up
the design formula, and should I be worried about
confounding?
"""

# Step 2: After discussion, ask for code

"""
That makes sense. Can you give me the R code to set up
the DESeqDataSet with batch correction and run the
differential expression analysis?
"""

# Step 3: Request comments

"""
Can you add comments explaining what each step does,
especially the design formula syntax?
"""

# Step 4: Final review after editing

"""
I modified the code to filter low-count genes differently.
Can you review this and check for any issues?
[paste edited code]
"""

🚀 Vibe Coding & Claude Code

Claude Code is Anthropic's CLI tool for agentic coding — it can read, write, and execute code directly in your terminal.

How Claude Code Works

  • Runs in your terminal with access to your local file system
  • Can read existing code, understand project structure, and make edits
  • Executes shell commands and runs tests autonomously
  • Asks for permission before destructive or sensitive operations
  • "Vibe coding" = describe what you want in natural language, Claude implements it

⚠️ Claude Code Security

Agentic tools that execute code come with risks. Recent security advisories for Claude Code:

Keep Claude Code updated, review commands before approving, and be cautious with untrusted repositories.
